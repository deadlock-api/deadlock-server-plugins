**1c3554a** (2026-05-02) — expose CBaseEntity.Friction, CCitadelPlayerPawn.RespawnTime

**67ac6e9** (2026-05-06) — expose entity collision
- New `CBaseEntity.Collision` property: reads `m_pCollision` pointer; returns `CCollisionProperty?`
  (null when pointer == 0, i.e. entity has no collision representation).
- New `CCollisionProperty` class (`DeadworksManaged.Api/Entities/CCollisionProperty.cs`):
  - Schema class `"CCollisionProperty"`: fields `m_vecMins` (Vector3), `m_vecMaxs` (Vector3), `m_flBoundingRadius` (float).
  - Exposes `Mins`, `Maxs` (read/write), `BoundingRadius` (read-only).
  - Convenience: `WorldMins = Mins + Owner.Position`, `WorldMaxs = Maxs + Owner.Position`.
  - **IMPORTANT: WorldMins/WorldMaxs assume identity rotation.** Source comment literal:
    "Assumes identity rotation." Inaccurate for rotated entities (doors, props, some NPCs).
  - `Contains(Vector3 point)` — inclusive AABB test against world-space box.
- New `BoundingBox` static utility class (`Math/BoundingBox.cs`):
  `BoundingBox.Contains(mins, maxs, point)` — inclusive per-axis test.

**93a3dd2** (2026-05-09) — hook and force false CServerSideClientBase::IsReservedSlot
- New sig in deadworks_mem.jsonc: `"CServerSideClientBase::IsReservedSlot"` → engine2.dll
  pattern `"40 53 48 83 EC ?? 83 B9 ?? ?? ?? ?? ?? 48 8B D9 0F 84"`.
- Native hook installed in PostInit (alongside FilterMessage hook) that **unconditionally
  returns false** — forcibly disables slot reservation on every connection check.
- **No managed API surface.** This is a native-only fix.
- Motivation: players were unable to join servers that appeared "full" because slot reservation
  was holding open slots for reserved-slot holders even when the server wasn't truly full.
- The hook is global and unconditional — there's no plugin API to toggle it.

**11cff37** (2026-05-09) — add linux path detection for the launcher
- Launcher-only change (Tauri app). Adds linux/flatpak Deadlock install path detection.
- Not plugin-relevant; not ingested into wiki.
